# TaskMate CLI

A simple terminal task manager made with Python.

It uses a simple list to store tasks while the program is running.

## Features

- Add a task
- View tasks
- Complete a task
- Delete a task
- Simple terminal menu
- Basic error handling

## Important

This version does **not** save tasks to a file.

When the program is closed, all tasks are removed.

## Technologies

- Python 3
- No external libraries
